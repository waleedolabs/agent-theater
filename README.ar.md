# 🎬 مسرح الوكيل

**بدل أن تحدّق في طرفية تمرّ أسطرها، شاهد وكيلك وهو يعمل.**

مسرح الوكيل يحوّل جلسة Claude Code إلى عرض سينمائي حيّ: يخطط الوكيل، ويقرأ مشروعك، ويكتب الكود سطرًا سطرًا، ويشغّل الاختبارات، ويجمّد المسرح كله حين يحتاج موافقتك. تجيب من المسرح نفسه، ويصل جوابك مباشرة إلى Claude Code.

## التشغيل

```bash
npx github:waleedolabs/agent-theater
```

هذا كل شيء (أو بدون طرفية: نزّل المستودع واضغط مرتين على **`Agent Theater.vbs`** في ويندوز أو **`Agent Theater.command`** في ماك. يعمل في الخلفية بلا أي نافذة ويفتح المسرح مباشرة، وللإيقاف استخدم ملف `Stop Agent Theater` المقابل. في ماك أول مرة: زر يمين ← فتح، لتجاوز تحذير الملف غير الموقّع). في أول تشغيل يربط نفسه مع Claude Code (يضيف بعض الخطافات المحلية إلى `~/.claude/settings.json` ويحتفظ بنسخة احتياطية)، ثم يشغّل خادمًا صغيرًا على جهازك ويفتح المسرح في المتصفح. أعد فتح أي جلسة Claude Code مفتوحة، ثم اعمل كالمعتاد.

يحتاج Node.js 18 أو أحدث، وClaude Code (في الطرفية، أو جلسة **Local** في تبويب Code داخل تطبيق Claude).

**أين يعمل:** Claude Code في الطرفية، وجلسات **Local** في تبويب Code بتطبيق Claude لسطح المكتب (مجرَّب هناك). **لا** يعمل مع محادثة claude.ai العادية لأنها بلا خطافات، ولا مع الجلسات السحابية لأنها لا تصل إلى جهازك. جُرّب على ويندوز مع تطبيق سطح المكتب؛ أما ماك ولينكس والطرفية فيُفترض أن تعمل بنفس الشكل لكنها لم تُختبر بعد. افتح Issue إذا لاحظت اختلافًا.

## ماذا سترى

| اللحظة | على المسرح |
|---|---|
| ترسل طلبك | بطاقة عنوان، ثم لوحة تخطيط تبقى حيّة طوال تفكير الوكيل |
| يضع الوكيل خطته | تتحول قائمة مهامه إلى كوكبة تضيء خطوة بعد خطوة |
| يقرأ الملفات | يفتح الملف كهولوغرام، ويسحب شعاع المسح محتواه إلى نواة الذكاء |
| يكتب الكود | تُكتب الأسطر مباشرة، مع شعاع طاقة من النواة إلى المؤشر |
| يعدّل | تحمرّ الأسطر القديمة وتتفتت حروفًا متساقطة، وتُكتب الجديدة مكانها |
| يشغّل الاختبارات | تصل النتائج واحدة تلو الأخرى مع مقياس للنتيجة، والفشل يهزّ المسرح بالأحمر |
| يطلب الإذن | يخفت كل شيء، ويرنّ إنذار، وتضغط **وافق / ارفض** في مكانك |
| ينتهي | تتجمع اللوحات في فسيفساء، وتتصاعد الأرقام، وتنطلق الألعاب النارية |

ومعها موسيقى خلفية ومؤثرات صوتية، وترجمة نصية بالعربية أو الإنجليزية، وضبط تلقائي للجودة حتى يبقى العرض سلسًا على الأجهزة المتوسطة.

## خطوة بخطوة

**ويندوز**
1. ثبّت [Node.js](https://nodejs.org) الإصدار 18 أو أحدث، وClaude Code.
2. افتح PowerShell ونفّذ `npx github:waleedolabs/agent-theater`. أو نزّل المشروع ZIP وفك الضغط واضغط مرتين على **`Agent Theater.vbs`** (لا تظهر نافذة، وتفتح المنصة في المتصفح).
3. أعد تشغيل Claude Code وأعطه مهمة وشاهد المنصة.
4. للإيقاف: **`Stop Agent Theater.vbs`** أو `npx github:waleedolabs/agent-theater stop`.

**ماك / لينكس**
1. ثبّت Node.js 18+ (`brew install node`) وClaude Code.
2. في Terminal نفّذ `npx github:waleedolabs/agent-theater`. أو نزّل المشروع واضغط مرتين على **`Agent Theater.command`** (أول مرة: كليك يمين ← Open).
3. أعد تشغيل Claude Code وأعطه مهمة.
4. للإيقاف: **`Stop Agent Theater.command`** أو `npx github:waleedolabs/agent-theater stop`.

**للإزالة الكاملة:** `npx github:waleedolabs/agent-theater uninstall` يحذف خطافاته فقط من `~/.claude/settings.json`.

## شارك جلساتك

**عن الخطة وشريط النسبة:** لا يعلن Claude Code خطته من نفسه، لذلك يعرض المسرح عادةً كل خطوة وقت حدوثها. وإذا ضغطت **طلب الخطة من Claude** (أو شغّلته بـ `--plan`) يطلب المسرح منه عبر hook أن يكتب قائمة مهام قصيرة أولًا، فتظهر كخطة مع نسبة مئوية. هي معطّلة افتراضيًا لأنها تضيف جملة إلى كل طلب وتستهلك بعض التوكنات.

كل طلب تشغّله يُسجَّل. اضغط **حفظ العرض** لتنزيله كملف صغير (مع خيار لإخفاء محتوى الملفات)، ويستطيع أي شخص إعادة تشغيله في [العرض التجريبي](https://waleedolabs.github.io/agent-theater/?lang=ar) عبر **فتح تسجيل**، أو بسحب الملف إلى الصفحة. وتبقى التسجيلات في الذاكرة فقط، ولا تُكتب في `~/.agent-theater/sessions` إلا إذا شغّلت مع `--save-sessions`.

تريد فيديو؟ اضغط **تسجيل فيديو** مرة واحدة واختر هذا التبويب، فيسجّل المسرح نفسه (مع صوته) من الطلب التالي حتى لحظة بعد الخاتمة، ثم ينزّل ملف `.mp4` أو `.webm`. زر Esc يلغي. الميزة اختيارية وتعمل في Chrome وEdge.

## الموافقات

حين يطلب Claude Code إذنًا والمسرح ظاهر أمامك، يظهر السؤال على المسرح:

- **وافق / ارفض**: يصل قرارك إلى Claude Code.
- **اترك القرار لـ Claude Code**: يعود السؤال إلى Claude Code كالمعتاد.
- إذا كان المسرح مغلقًا أو في تبويب بالخلفية، يسألك Claude Code فورًا. وإن لم تردّ خلال 30 ثانية يعود السؤال إليه أيضًا (غيّرها بـ `--wait 60`).

## الأوامر

```bash
npx github:waleedolabs/agent-theater              # تشغيل المسرح
```

## الخصوصية والأمان

يرى مسرح الوكيل ما يفعله Claude Code، لذلك هذا بالضبط ما يلمسه. لا يوجد برنامج يستطيع أن يعد بـ«أمان 100%»؛ هنا ما يفعله وما يتعمّد ألّا يفعله وحدوده.

**أين تذهب بياناتك**
- كل شيء يبقى على جهازك. الخادم يستمع على `127.0.0.1` فقط، والصفحة التي يقدّمها لا تحمّل شيئًا من الإنترنت (لا خطوط ولا سكربتات ولا تحليلات ولا قياسات). صفحة العرض العامة (GitHub Pages) تستخدم خطوط Google وفيها بيانات تجريبية وهمية فقط.
- العروض المنتهية تُحفظ **في الذاكرة فقط** (آخر 20) وتختفي عند إيقاف المسرح. لا يُكتب شيء على القرص إلا إذا شغّلته بـ `--save-sessions`. وملف السجل يحفظ أسماء الأحداث فقط (مثل «PreToolUse · Read») ولا يحفظ المحتوى أبدًا.
- لا يُرفع شيء إلى أي مكان. المشاركة تتم فقط بملف تنزّله وترسله أنت بنفسك.

**ما يُخفى قبل أن يُعرض أو يُخزَّن**
- لا تُقرأ ولا تُعرض محتويات الملفات الحساسة: `.env*` و`.npmrc` و`.netrc` و`.git-credentials` و`*.pem` و`*.key` و`*.p12` و`id_rsa*` و`credentials*` و`secrets*` و`*.tfstate` و`*.tfvars` وملفات JSON لحسابات الخدمة وكل ما داخل `.ssh` و`.aws` و`.gnupg` و`.kube` و`.docker` و`.azure`. يعرض المسرح بدلًا منها «hidden: sensitive file».
- مخرجات الأدوات التي لا يحتاجها العرض تُحذف (محتوى الملفات المقروءة، صفحات الويب، نتائج البحث). يُحتفظ فقط بمخرجات الأوامر (للاختبارات والأخطاء).
- الأسرار في الأوامر والمخرجات وفي طلبك تُخفى بأفضل جهد: المفاتيح الخاصة وJWT ومفاتيح API (`sk-…` و`ghp_…` و`AKIA…` و`xox…` و`npm_…`) و`user:password@` في الروابط و`Bearer …` و`password=…` و`token=…` والسلاسل الطويلة العشوائية.
- المسارات في العروض المحفوظة تصبح نسبية (مجلد المشروع يصبح `.` ومجلد المستخدم `~`).

**حدود يجب أن تعرفها**
- الإخفاء يعتمد على الأنماط. سرّ لا يشبه الأسرار (كلمة مرور قصيرة في جملة عادية، أو صيغة مخصصة) قد يفلت. **اقرأ العرض قبل أن تشاركه.** خيار «إخفاء محتوى الملفات» مفعّل افتراضيًا عند الحفظ، ويمسح محتوى كل ملف ظاهر.
- الملفات العادية التي يقرؤها Claude أو يكتبها (شيفرتك) تُعرض على المسرح وتُحفظ في العرض الموجود بالذاكرة. إن كانت شيفرتك خاصة فاعتبر العرض المشارَك أو تسجيل الشاشة خاصًا أيضًا.
- مسجّل الفيديو يسجّل تبويب الشاشة، فيسجّل كل ما فيه.
- Claude Code هو من يقرر ما يفعله، والمسرح يراقب فقط. ولا يرى أكثر من أحداث الـ hooks التي يرسلها Claude Code (ولا يقرأ ملف المحادثة أبدًا).

**التحكم بالوصول**
- الـ hooks موثّقة برمز عشوائي، وصفحة المسرح برمز آخر. والموافقات (سماح/رفض) تتطلب رمز الصفحة.
- أي طلب برأس `Origin` أو `Host` غريب يُرفض (حماية من صفحات الويب التي تحاول التواصل مع خادمك المحلي، بما فيها DNS rebinding).
- إن لم يكن المسرح شغّالًا فإن Claude Code يعمل تمامًا كما كان.

**التغييرات على إعدادات Claude Code**
- التثبيت يضيف بضعة hooks من نوع `http` إلى `~/.claude/settings.json` (بعد حفظ نسخة احتياطية). والأمر `agent-theater uninstall` يزيل هذه الـ hooks فقط.
- طلب قائمة المهام **معطّل افتراضيًا**. وإذا فعّلته (زر «طلب الخطة من Claude» أو `--plan`) تُضاف جملة قصيرة إلى كل طلب ما دام المسرح مفتوحًا، وهذا يستهلك بعض التوكنات.
- مشهد «التفكير» تمثيل بصري وليس تفكير Claude الحقيقي، فـ Claude Code لا يكشف تفكيره للـ hooks.
